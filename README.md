# SommerBryllup2027

A responsive Save the Date site with a layered scroll-parallax composition.

All supplied illustrations, birds, date treatment, and the Mélodrame font are in `assets/`, so the folder is ready to upload as one GitHub Pages project. Layer numbers determine their depth: `1` moves most and `11` moves least.

## Edit copy

Update the names in `index.html`. The supplied `10Juli.png` is used for the date treatment.

## Publish on GitHub Pages

1. Create a GitHub repository called `SommerBryllup2027` and upload these files.
2. In GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, then `main` and `/(root)`.
4. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/SommerBryllup2027/`.

There is no build step or server to configure.
